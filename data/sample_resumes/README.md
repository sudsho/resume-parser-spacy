# Sample resumes

Synthetic resumes used as fixtures for tests and the manual smoke run. Names and contact details are fake. Real public datasets of resumes are scarce, so I generated a small set that covers common layouts (single column, multi section, with and without a contact block at top).

To regenerate or extend the set, just drop more `.txt`, `.pdf`, or `.docx` files in this folder. Tests will pick them up automatically.
